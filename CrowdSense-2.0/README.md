# CrowdSense 2.0 – Smart Crowd Monitoring System

## Project Overview
CrowdSense 2.0 is an upgraded version of the Smart Visitor Counter project. It is designed to monitor visitor counts and provide a dashboard for viewing crowd activity.

## Technologies Used
- AWS Lambda
- Amazon DynamoDB
- Amazon API Gateway
- Amazon S3
- HTML
- CSS
- JavaScript

## Features
- Visitor count tracking
- Entry and exit simulation through the dashboard
- AWS-based visitor count storage
- Visitor event history backend
- Dashboard for crowd monitoring

## Project Status
The software prototype and AWS backend have been developed and tested. ESP32 hardware integration is planned as the next phase.

## Future Enhancements
- ESP32 sensor integration
- Automatic entry and exit detection
- Real-time crowd monitoring
- Occupancy alerts and analytics


# Smart Visitor Counter

## Project Overview
Smart Visitor Counter is an AWS-based project designed to count visitors and display the total count on a web dashboard.

## Technologies Used
- AWS Lambda
- Amazon DynamoDB
- Amazon API Gateway
- Amazon S3
- HTML
- CSS
- JavaScript

## Features
- Automatic visitor count updates
- Cloud-based data storage
- Web-based dashboard
- Real-time visitor count retrieval

## Project Objective
To develop a cloud-based visitor counting system using AWS services.
